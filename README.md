添加的快捷键：

mod+` : 创建临时终端

mod+shift+f ： 真正全屏

mod+ctrl+q : 刷新配置

mod+n : 打开网络管理器(nmtui)

mod+g : 切换网格布局

mod+q : 锁屏

mod+shift+j : 窗口向下移动 

mod+shift+k : 窗口向上移动
