### dwm添加的快捷键：

mod+` : 创建临时终端

mod+shift+f ： 真正全屏

mod+ctrl+q : 刷新配置

mod+n : 打开网络管理器(nmtui)

mod+g : 切换网格布局

mod+q : 锁屏

mod+shift+j : 窗口向下移动 

mod+shift+k : 窗口向上移动 

mod+a : 让当前聚焦窗口变成黏窗口

mod+v : 打开剪贴板

### st添加的快捷键:

alt+1~8: 切换终端主题

ctrl+1 : 放大字体

ctrl+2 : 缩小字体

ctrl+0 : 默认字体大小

alt+l : 复制网址
